## Descripción

Este proyecto es una calculadora básica desarrollada en Python. Su propósito es practicar la programación y aprender a utilizar Git y GitHub para guardar y compartir código.

## Funciones

- Sumar dos números.
- Restar dos números.
- Multiplicar dos números.
- Dividir dos números.
- Calcular potencias.
- Validar los datos introducidos.
- Evitar la división entre cero.

## Requisitos

- Tener Python instalado.
- Contar con una terminal o un editor de código.

## Cómo ejecutar el programa

Abre una terminal en la carpeta del proyecto y ejecuta:

```bash
python main.py
```

En Windows también puedes usar:

```powershell
py main.py
```

## Ejemplo

Si seleccionas la opción 1 e introduces los números 8 y 5, el programa mostrará:

```text
Resultado: 13
```
